# Play Store 등재 문구 (v3.4.1+24)

Play Console → **스토어 등재정보**에 그대로 붙여 넣을 수 있는 확정 문구.
글자 수는 Play Console 한도 기준으로 맞춰 두었다(한글 1자 = 1자).

기능이 바뀌면 **이 파일을 먼저 고치고** 콘솔에 반영한다. 출시 *절차*는
`PLAY_STORE_LAUNCH.md`(미커밋), 체크리스트는 `RELEASE_CHECKLIST.md` 참고.

---

## 앱 이름 (한도 30자)

```
연산 히어로 - 초등 수학 연산
```

> 대안(짧게): `연산 히어로` / 검색 노출을 더 노릴 때: `연산 히어로 - 초등수학 구구단`

## 짧은 설명 (한도 80자)

```
광고도 인터넷도 없이! 사칙연산·구구단을 게임처럼 익히는 초등 저학년 수학 앱
```

## 자세한 설명 (한도 4000자)

```
🦸 연산 히어로 — 우리 아이 첫 연산 습관

덧셈·뺄셈·곱셈·나눗셈을 게임처럼 즐기면서 익히는 초등 저학년(6~9세) 수학 앱입니다.
광고가 없고, 인터넷 연결도 필요 없고, 결제도 없습니다. 설치하면 바로 시작합니다.


📚 차근차근 올라가는 학습 모드

• 사칙연산 5단계 — 1자리부터 3자리까지, 아이 수준에 맞춰 단계를 고르세요
• 도전 / 연습 / 타임어택 / 연속 도전 — 같은 문제도 네 가지 방식으로
• 구구단 — 원하는 단만 골라 9문제 집중 연습
• 혼합 연산 — 5 + 3 × 2 - 1 처럼 여러 연산이 섞인 식
• 방정식 — 7 + ? = 12, 숨은 수를 찾아요
• 플래시 암산 — 잠깐 보여 준 식을 기억해서 풀기
• 어림셈 — 정확히 계산하지 않고 어림으로 고르기
• 부호 맞추기 — 가려진 +, -, ×, ÷ 를 채워 식을 완성


🎮 연산으로 즐기는 미니게임 8종

• 아레나 — 웨이브를 버티는 생존 모드! 웨이브를 깰 때마다 힘을 하나 골라 강해지고,
  3판마다 보스가 나타납니다. 갈수록 적이 늘고 시간이 줄고 숫자도 커져요
• 몬스터 처치 — 떨어지는 몬스터를 답으로 물리치기
• 풍선 터뜨리기 — 같은 답의 풍선 찾기
• 타워 디펜스 — 성을 지켜라!
• 두더지 잡기 — 빠르게 답 입력하기
• 숫자 사다리 — 정답 칸만 밟고 올라가기
• 물고기 잡기 — 헤엄치는 정답 낚기
• 저울 맞추기 — 어느 쪽이 더 큰지 어림으로 판단하기

게임마다 최고 기록이 남아서 "어제의 나"와 겨룰 수 있어요.


👨‍👩‍👧 부모와 함께하는 학습

두 기기를 가까이 두고 연결하면, 아이가 푸는 화면을 부모님이 실시간으로 보면서
난이도를 바꿔 주고, 칭찬 이모지를 보내고, 화면에 직접 선을 그어 풀이를 도와줄 수
있습니다. 인터넷을 거치지 않는 근거리 연결이라 밖에서도 됩니다.


🏅 스스로 자라는 재미

• 도장판 — 조건을 채우면 자동으로 받는 배지 + 직접 만드는 나만의 도장
• 일일 미션 — 매일 바뀌는 3가지 목표
• 연속 출석 — 며칠 이어서 공부했는지 한눈에
• 오답 노트 — 틀린 문제만 모아 다시 풀기
• 학습 통계 — 연산별·단계별 정답률과 약점 분석, 다음에 뭘 하면 좋을지 추천
• 주간 리포트 — 최근 7일 학습을 한 장으로 정리해 부모님께 공유


👧👦 형제자매도 함께

프로필을 여러 개 만들 수 있어요. 기록·도장·최고 점수가 아이마다 따로 저장됩니다.


🔒 안심하고 맡기세요

• 광고 없음 — 실수로 눌릴 배너도, 영상 광고도 없습니다
• 인앱 결제 없음 — 추가 결제로 유도하지 않습니다
• 개인정보 수집 없음 — 이름·기록은 기기 안에만 저장되고 서버로 보내지 않습니다
• 계정·로그인 없음 — 설치하면 바로 시작
• 오프라인 — 비행기 모드에서도 모든 기능이 그대로

권한 안내: 블루투스·근처 기기 권한은 "부모와 함께하는 학습"에서 옆에 있는 기기와
연결할 때만 사용합니다. 위치를 파악하거나 저장하지 않으며, 그 기능을 쓰지 않으면
권한을 허용하지 않아도 나머지 모든 기능을 사용할 수 있습니다.


매일 5분, 한 판씩. 연산이 재미있어지는 순간을 만들어 주세요!
```

## 새로운 기능 / 출시 노트 (한도 500자)

```
오늘의 미션을 더 쉽게 시작할 수 있게 다듬었어요.

• 홈 화면의 오늘의 미션 카드에 "5문제 시작" 버튼 추가
• 짧게 한 판만 풀어도 일일 미션을 채워 가기 쉽게 개선
• 최근 약점 기록이 있으면 아이에게 맞는 연산과 레벨로 바로 시작
• 기록이 없을 때는 쉬운 덧셈 1단계부터 시작

매일 부담 없이 5문제씩, 연산 습관을 이어 가 보세요!
```

## 콘솔 입력 참고

| 항목 | 값 |
|---|---|
| 카테고리 | 교육 (또는 게임 > 교육) |
| 태그 | 수학, 초등, 사칙연산, 구구단, 학습 게임 |
| 광고 포함 | **아니요** |
| 인앱 구매 | **없음** |
| 콘텐츠 등급 | 전체 이용가 (설문에서 폭력/공포/도박 전부 "아니요") |
| 데이터 안전 | 수집·공유 데이터 **없음**. 데이터는 기기에만 저장 |
| 대상 연령 | 만 5세 이하 제외 — 6~9세 중심 (Designed for Families 참여 시 연령대 선택) |
| 개인정보처리방침 | 저장소 `privacy-policy.md` 를 공개 URL로 게시한 주소 |

**권한 신고(민감 권한 문항)**: 블루투스·근처 기기 권한은 근거리 P2P 학습
기능에만 사용하며 위치 추론에 쓰지 않음(`neverForLocation` 명시). 자세한 근거는
`PARENT_COOP_LEARNING.md` §3.

**스크린샷 후보** (폰 최소 2장, 권장 4~8장): 홈(학습 탭) / 아레나 플레이 /
게임 탭 8종 / 결과 화면 / 도장판 / 학습 통계 / 함께 학습 부모 화면.
현재 `assets/store/` 에 기존 버전 스크린샷이 있으며, **아레나 화면은 새로
찍어 추가**해야 한다.
